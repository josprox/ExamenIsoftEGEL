# Interfaz React

La interfaz de práctica del EGEL Plus ISOFT usa React, TypeScript, Vite y Tailwind. El temario y las preguntas se cargan desde la API Laravel; los archivos fuente viven en `../contenido/`.

Desde la raíz del proyecto, instala dependencias con `npm --prefix frontend install` y ejecuta `npm run dev:frontend`. Laravel debe estar disponible en `http://127.0.0.1:8000`; Vite redirige `/api` y `/biblioteca-files` a ese servidor.

La navegación principal prioriza práctica, guías, progreso y biblioteca. El chuletario de comandos permanece como material complementario en el pie de página.
